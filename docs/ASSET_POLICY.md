# Assets

Default boat appearance is generated from boxes/crossbars; inertia and
hydrodynamic parameters are separate engineering values. Optional manufacturer
CAD can be prepared locally. Do not commit manufacturer STL/rotor geometry
without an applicable redistribution grant. Original procedural water assets
are generated by tools/generate_public_assets.py; shaders keep Apache notices.
The standard tag36h11 pattern is generated, with a0.432m black-border side.

Do not commit local firmware executables, raw reference archives, private
correspondence, captures or machine-specific build/log folders.

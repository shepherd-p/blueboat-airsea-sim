The standalone BlueBoat world uses its own water visual and does not use the
original H-SPAR Baylands or Sydney landscape meshes. These optional meshes are
omitted from the compact source ZIP; the source checkout retains them.

Download the matching upstream files if using the original WAM-V/VRX launches:
https://github.com/naviiidz/h-spar-sim/tree/2fb6b980e224c220e5c15a696a9933b7448f0ad8/ros2_ws/src/usv_control/worlds
